# JAVA-OnlineBankingApplication

A robust Java-based console banking application.

## Features
- **User Authentication**: Secure Login and Registration.
- **Banking Operations**: 
  - Deposit and Withdraw funds.
  - **Transfer Money**: Send funds instantly to other users.
  - Check Balance.
- **Account Management**: Change your password securely.
- **Transaction History**: View detailed logs of all your deposits, withdrawals, and transfers.
- **Persistence**: All user data and transactions are saved automatically.

## How to Run
1. Open terminal in the project directory.
2. Compile the code:
   ```bash
   javac *.java
   ```
3. Run the application:
   ```bash
   java BankApp
   ```
